Fixes:
1. Role check: Object.hasOwn(ROLE_LABELS, role) replaces `role in ROLE_LABELS`, so inherited
   names (toString, constructor, __proto__, hasOwnProperty) are rejected.
2. Image URLs: an image is passed to next/image only when it is https on res.cloudinary.com,
   with no port or credentials. That host matches images.remotePatterns, and a test keeps the
   two in sync; the allowed host list is unchanged. Any other URL shows the placeholder instead
   of reaching next/image. An item with a missing or unusable image is still shown, rather than
   rejecting the whole outfit.
3. Placeholder: "Image unavailable" (role="img", named "Image unavailable for <item name>") for
   a missing or unsupported URL, or when the photo fails to load (next/image onError). The
   item's name and role stay visible. A new URL resets the failed state.
4. 401: the alert keeps "Your session has ended. Sign in again to continue." and offers a
   Sign in link to /sign-in?reason=session-ended instead of Try again. That path matches
   SIGN_IN_SESSION_ENDED_PATH, which a test checks.
