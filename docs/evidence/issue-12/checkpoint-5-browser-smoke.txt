=== RESULTS ===
Run 1 (first run, US7 file only): 16 passed, 1 failed.
  Failed: "has no unexpected console errors or failed application requests". There were 4
  failed requests, all net::ERR_ABORTED on Next.js background prefetches (/home?_rsc=...,
  /wardrobe/new?_rsc=...).
  Investigation: the test now records Chrome's own `canceled` flag and the resource type. Every
  aborted request is a canceled Fetch prefetch, and every existing route that had one canceled
  also had successful 200 prefetches in the same run (/home 5, /wardrobe/new 6, /sign-in 3,
  /sign-up 2, /outfits/create 2). Chrome cancels in-flight prefetches when the page navigates
  away, so this is a test-environment effect, not a product bug. Only requests that Chrome
  flags as canceled, with net::ERR_ABORTED and an _rsc prefetch URL, are set aside. Every other
  failed request, error response and console error still fails the test.
Run 2 (US7 file): 17 passed.
Full smoke suite (npm run test:smoke, browser on): 3 files, 52 passed
  (productionAuth 20, outfitGeneration 17, googleAuth 15).
Without SMOKE_CHROME_PATH: 6 passed, 11 skipped (the default npm run test:smoke behaviour).
