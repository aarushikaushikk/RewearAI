=== BEHAVIOUR ===
Given the item IDs of outfits already shown, generateOutfit returns a combination not among them:
 - It only has to differ by at least one item; the rest of the outfit can stay.
 - It prefers pieces shown least, so repeated requests mix and match across the wardrobe.
 - Leaving out a suitable piece (for example shoes) does not count as a new outfit.
 - When every combination has been shown, it answers { status: 'no_alternative' }.
 - Shown IDs only rule combinations out. They never make an unavailable, unsuitable, or other
   user's item eligible. Season and formality rules still apply.
 - The search is bounded (MAX_CORE_CANDIDATES cores, MAX_OPTIONS_PER_PIECE options per piece).
