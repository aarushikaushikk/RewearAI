=== BEHAVIOUR ===
paletteOf sorts an outfit's colors into tonal, neutral, one_accent, paired or bold.
Neutral: Black, White, Grey, Charcoal, Beige, Camel, Brown, Navy, Indigo. Multicolor is a pattern.
generateOutfit ranks valid outfits by:
  1. has shoes when suitable shoes exist   2. fewest pieces already shown (US8)
  3. calmer palette (new)                  4. input order (newest first)
Color only ranks. It never makes an outfit impossible, never makes an unavailable, unsuitable, or
other user's item eligible, and on Try another unseen pieces still come before a calmer palette.
The result reports its `palette`. The search stays bounded (MAX_CORE_CANDIDATES, MAX_OPTIONS_PER_PIECE).
