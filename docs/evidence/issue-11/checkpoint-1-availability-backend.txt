=== SECURITY BEHAVIOUR COVERED ===
- The CSRF origin check runs first (403), including through the real route's PATCH export.
- The session decides the owner (401 without one). The owner is part of the database filter, so
  another user's item is never matched or changed.
- Another user's item and a missing item give the same 404 "We couldn't find that item.", so
  item IDs can't be probed.
- Malformed owner and item IDs return before any query is made.
- The body must be exactly { isAvailable: boolean }. Strings such as "false", numbers, null and
  extra fields such as an owner get a 400, with nothing changed.
- Outages give a 503 with a safe message. Driver errors give a 500 with a generic message. Logs
  and responses contain no driver details (host, credentials, raw error text).
