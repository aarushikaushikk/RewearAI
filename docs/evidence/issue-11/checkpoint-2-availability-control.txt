=== BEHAVIOUR COVERED (12 tests) ===
- Status shown as text ("Available"/"Unavailable"); a symbol is added but is hidden from screen
  readers, so status is never conveyed by color alone.
- The button's accessible name includes the item: "Mark unavailable: White Button-down".
- Available to unavailable and back: PATCH to the URL-encoded item ID with
  { isAvailable: <new value> } and a JSON content type.
- While saving: the button reads "Saving…" and is disabled with aria-busy; the old status stays.
- On success: the status comes from the server's response, a polite status region announces
  "<item> marked unavailable." and onChange receives the updated item.
- On failure: the previous status stays; an alert explains, in the app's own words, a 401, 403,
  404, 503 or other error, a network failure, or a success response without a usable item.
  Server error text is never shown. A retry clears the error.
- Repeated clicks while saving send one request.
- A new isAvailable prop from the parent replaces the shown status.
