=== PROPOSED DEPENDENCY (needs both partners' approval) ===
Package:   @huggingface/transformers 4.3.2 (Transformers.js), Apache-2.0
           Depends on onnxruntime-web (currently a dev build, 1.31.0-dev), plus sharp and
           onnxruntime-node for Node. Those two must be kept out of the browser bundle.
Model:     Xenova/clip-vit-base-patch32, MIT. Zero-shot image classification.
           Quantized download about 154 MB, once per browser, then cached.
           OpenAI's CLIP model card describes the model as intended for research.
Alternative: Marqo/marqo-fashionSigLIP, Apache-2.0, trained on fashion images, about 205 MB
           quantized. Not yet confirmed to load in Transformers.js.
Browsers:  WebAssembly backend in current Chrome, Edge, Firefox, and Safari; WebGPU is optional.
           Low-memory phones may fail to load the model; that returns "unavailable" and the user
           enters details manually.
Cost:      None per image. Model files are served free from Hugging Face's CDN (or could be
           self-hosted in /public).
