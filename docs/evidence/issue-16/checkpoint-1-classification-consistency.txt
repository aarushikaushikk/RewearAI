=== RULES ===
1. Category/style disagreement. A style -> category map is built from GARMENT_PROMPTS in
   clothingLabels.ts (each style appears once; a new test enforces this). After both leaders are
   picked, if the style's own category isn't the suggested category, the category's confidence is
   set to "low", so normalizeClassification reports it "uncertain" and it must be reviewed.
   Only the category is lowered: a confident style holds >= 0.6 of the garment score, so its own
   category (>= 0.6) must lead and they agree. A disagreeing style is therefore always already low.
2. Retried analysis. applySuggestions now returns a field the user touched (edited) unchanged.
   Before, it reset such a field to reviewed: true. A user who unticked an uncertain value, or
   changed a value back to the uncertain suggestion, would then have it accepted by a later
   result without confirming it. In the current UI a second result arrives only through
   "Retry analysis", which is shown only after a failed analysis, so this path wasn't reachable.
   The fix is a safeguard for the review rule.

Unchanged: CONFIDENT_MIN_SHARE = 0.6 and CONFIDENT_MIN_MARGIN = 0.2 (a test now pins both); season
and formality are still always low; the statuses suggested/uncertain/missing/invalid; classifier
failure and manual-entry paths (existing tests pass unchanged).
