=== DECISION ===
Negative feedback changes future recommendations: a combination marked Not helpful for an occasion
ranks below every other valid one, so it's returned only when nothing else is left. Positive
feedback doesn't change ranking. The UI says only that ("Outfits you mark Not helpful are skipped
for this occasion when another combination is available."), never that the app "learns".
