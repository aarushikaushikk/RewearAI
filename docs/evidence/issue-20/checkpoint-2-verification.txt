=== CHANGE ===
When a save answers 404 ("We couldn't find that image. Please upload it again."), the details step now
offers "Upload photo again". It re-sends the photo the form kept, without leaving the details step:
details, review state and the analysis result are untouched, and only the stored image changes.
Save and the fields are disabled while it runs ("Uploading your photo again."). A failure is reported
with the upload messages, and the button stays when a retry can help. Success shows "Your photo was
uploaded again. You can save now." No server change: the routes already refused a missing image and
answered a retried save with the existing item.
